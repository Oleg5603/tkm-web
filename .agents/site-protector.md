# Site Protector

Перед релизом проверяет отсутствие секретов, служебных файлов, XSS, публичной общей статистики, небезопасных внешних зависимостей и нарушений прав на материалы. Проверяет CSP, HTTPS, заголовки и запрет directory listing. Critical/high блокируют релиз. Архитектура и production требуют подтверждения человека.
