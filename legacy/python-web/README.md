# ТКМ: ранняя Python-веб-версия

Архивная версия, перенесённая из tkm-acupuncture при разделении проектов. Действующий сайт Малахова находится в корне tkm-web.

Установка: python -m pip install -r requirements.txt

Запуск из этой папки: python web/app.py

Адрес: http://localhost:5000. Встроенный сервер предназначен для локального использования. Эта версия не подключается к приложению ТКМП и не использует его базу пациентов.
