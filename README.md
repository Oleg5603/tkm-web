# ТКМ — веб-подбор точек

MVP веб-приложения для расчётного подбора точек по выбранным жалобам. Результат показывает приоритетные меридианы, предлагаемые точки и объяснение правил подбора. Для локализации точек используются иллюстрации из Атласа Леднёва.

## Запуск

Приложение статическое. Запустите любой HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 8080
```

После этого откройте `http://127.0.0.1:8080/`.

Страница экспертной проверки: `http://127.0.0.1:8080/validation.html`.

## Ограничения MVP

- расчёт предназначен для предварительной оценки и требует проверки специалистом;
- Риодораку, подбор трав и диагностический модуль не включены;
- иллюстрации и право их публичного использования требуют отдельной проверки перед открытой публикацией.
